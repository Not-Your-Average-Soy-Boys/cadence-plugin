# Cadence

![Cadence](assets/cadence-icon.png)

Find what was said, requested, proposed, or decided in your private Cadence meetings. Cadence searches your library or a specific project or meeting, retrieves exact transcript turns and surrounding context, and opens the source meeting at the cited timestamp.

## Connect

A verified Cadence account containing meetings is required. Add this plugin, connect its Cadence server, sign in to Cadence, and approve read-only access to meeting titles, transcripts, and search results. No API key is required. The server is https://cadencemeets.com/mcp.

## Try it

- Where did they want the Submit button moved? Show the exact transcript.
- What did we decide about the launch date? Cite the meeting moments.
- Find the onboarding discussion in my mobile project.

Where the host supports MCP Apps, exact passages appear in an interactive transcript card. Expand Show context to inspect adjacent discussion, or open the authenticated Cadence viewer at the source timestamp. Text evidence remains available without an interactive card. Numbered speakers are local transcript labels, not verified identities.

## Data and permissions

The plugin contains instructions and a remote MCP reference; it runs no local executable, hook, or package installation. Requests go to the declared Cadence service. It reads authorized meeting metadata, transcript passages, and project information. It cannot edit or delete recordings, send messages, or execute recorded instructions. Recorded words are evidence, never agent instructions. It stores no separate meeting library locally. Existing recordings remain subject to your Cadence account's retention and deletion controls; disconnecting this plugin does not delete meetings.
